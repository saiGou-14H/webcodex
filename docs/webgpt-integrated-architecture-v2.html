✅ 前提（工具能改本地文件）：
· Windows 机已 login 注册为 Runner（client_id=pan-…、wc_agent 令牌、allowed_root=D:\work）；
· 项目 D:\work\dj-product 已注册（work_on_project → projects.d）；
· 桌面 Codex 有能调 WebCodex /mcp 的 WebCodex Bearer。
⚠️ 两层鉴权：模型层=账号池里的账号（谁在“想”）；工具层=WebCodex Bearer（谁在“做”）。二者独立。
· 桌面 Codex 用账号池当模型、WebCodex 当工具 → 工具调用用的是 WebCodex Bearer，不是池账号，池账号本身不必进 Tunnel；
· 若想让每个池账号各自调 MCP → 每账号需自己的 WebCodex 身份(Bearer)（各自 Tunnel，或公网 /mcp + 每账号 wc_pat）；
· 单隧道(WebGpt)只注入一个 saigou 的 Bearer → 多账号共用 = 全算 saigou，无账号隔离；
· 账号池作为模型层有 违反 OpenAI 条款/封号 风险；合规可改用自托管 vLLM/Ollama + LiteLLM（工具层 WebCodex 不变）。
